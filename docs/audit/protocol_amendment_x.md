# Frozen repetition compatibility marker

The recorded repetition scope uses search roots 42, 43 and 44, Q=400 and K=8. The original per-architecture seed derivation, ledger accounting and exact per-run settings are retained in the production entrypoints and experiments/manifest.json.

Timed measurements require the shared resource lock and the recorded resource checks. Untimed quality runs retain their separate timing scope. This marker supports the existing entry compatibility check; it does not activate a historical campaign queue.
